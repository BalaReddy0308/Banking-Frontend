# Banking Frontend — Enterprise Starter

This repository is a production-minded starter for a digital banking front-end built with React + TypeScript, Vite, Material UI, TailwindCSS and SASS. It includes a design system skeleton, Redux Toolkit store, React Query setup, and a mock API (MSW) for local development.

Quick start

1. Install dependencies

```powershell
cd "C:/Users/Bala/OneDrive/Desktop/Silicon Valley/banking-frontend"
npm install
```

2. Run development server

```powershell
npm run dev
```

Notes
- The mock API runs automatically in development via MSW.
- The project uses strict TypeScript settings and Material UI theming in `src/design`.
